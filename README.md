# YouTube Material 3 Expressive (`v1.0.0`)

Полный редизайн YouTube в стиле **Material Design 3 Expressive** для Chrome, Edge и Яндекс Браузера.

## Возможности

- **Живая палитра RGB** — полный перекрас акцента, текста и кнопок YouTube по ползунку RGB в стиле MD3.
- **Перерисованные иконки** — векторные иконки *Material Symbols Rounded* с настройкой размера и скругления подложек.
- **48 MD3-форм аватарок** — для каналов, ленты и комментариев с плавной анимацией смены по часовой стрелке.
- **Тональные подложки** — единые карточки метаданных под видео (канал, просмотры, дата, длительность) и просмотры Shorts.
- **Удобный интерфейс** — скрытие рекламных баннеров, совместимость с *Return YouTube Dislike* и кнопка **«Параметры»**, которая скрывается при скролле вниз и возвращается при прокрутке вверх.

> **⚠ ВАЖНО:** при светлой теме YouTube часть текста отображается чёрным цветом. Обязательно включите **тёмную тему YouTube** перед использованием расширения!

## Структура проекта

- `manifest.json` — манифест расширения (Manifest V3)
- `icons/` — иконки (`icon16.png`, `icon48.png`, `icon128.png`)
- `popup/` — всплывающее окно настроек (`popup.html`, `popup.css`, `popup.js`)
- `src/` — фоновый worker, стили и движки цветов/форм/иконок (`background.js`, `content.js`, `md3-color.js`, `md3-shapes.js`, `md3-icons.js`, `md3-youtube.css`)

## Установка

1. Скачайте готовый ZIP из раздела **Releases** (или **Code → Download ZIP**) и распакуйте архив в отдельную папку.
2. Откройте в браузере `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с файлом `manifest.json`.
