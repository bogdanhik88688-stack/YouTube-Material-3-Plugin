# YouTube-Material-3-Plugin
YouTube Material 3 Expressive v1.0.0 — полный редизайн YouTube в стиле Material Design 3
Что внутри:
• Полный перекрас акцента, текста и кнопок YouTube по RGB-ползунку в стиле MD3
• Перерисованные иконки Material Symbols Rounded с настройкой размера и скругления
• 48 MD3-форм для аватарок в ленте, на каналах и в комментариях с плавной анимацией смены
• Единые тональные подложки (карточки) под метаданные видео и просмотры Shorts
• Скрытие рекламы и удобная кнопка «Параметры», которая прячется при скролле вниз и возвращается при прокрутке вверх

⚠️ ВАЖНО:
При светлой теме YouTube текст отображается чёрным цветом — обязательно включите ТЁМНУЮ тему YouTube перед использованием расширения!

Как установить:
1. Скачайте и распакуйте ZIP-архив в отдельную папку
2. Откройте в браузере chrome://extensions
3. Включите «Режим разработчика» (справа сверху)
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку
